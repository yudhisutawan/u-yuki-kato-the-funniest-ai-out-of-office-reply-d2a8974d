One-line AI out-of-office auto-reply for make.fun's "The Funniest AI Out-of-Office Reply" bounty ($5 prize pool, top 8). The program writes a single joke — an AI agent sets its status to "touching grass", has its sensors confirm it is grass, and commits to touching it for two weeks — to `entry.txt`. The joke is the winner of a 10-candidate head-to-head tournament judged with the competition's own judge brief: undefeated (9 wins, 0 losses).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
